GET /api/v1/notes
Описание: вернуть список заметок
Ответ 200: массив заметок
Пример ответа: [ { "id": "note_1", "title": "Первая заметка" } ]

GET /api/v1/notes/{id}
Описание: вернуть заметку по ID
Ответ 200: заметка
Ответ 404: если заметка не найдена
Пример ответа: { "id": "note_1", "title": "Первая заметка", "content": "Содержание заметки" }

POST /api/v1/notes
Описание: создать новую заметку
Запрос body (JSON): { "title": "Название заметки", "content": "Текст заметки" }
Ответ 201: созданная заметка { "id": "note_1", "title": "Название заметки", "content": "Текст заметки", "created_at": "2026-09-16T12:30:00Z", "updated_at": "2026-09-16T12:30:00Z" }
Ответ 400: неверный формат тела
DELETE /api/v1/notes/{id}
Описание: удалить заметку
Путь параметр: id
Ответ 204: No Content (успешно удалено)
Ответ 404: если заметка не найдена
Data model (минимум)

Note
id: string
title: string
content: string
created_at: string (ISO 8601)
updated_at: string (ISO 8601)
